Job Radar als App über Cloudflare Pages

Das Repo ist bereits vorbereitet.
Cloudflare soll direkt den Ordner public veröffentlichen. Die App besitzt Manifest, Service Worker, Installationsbutton und eigenes App-Icon.

Cloudflare einmalig verbinden

  1. Cloudflare öffnen → Workers & Pages.
  2. Create application → Pages → Connect to Git.
  3. GitHub verbinden und das Repository plasma19911/Job-Radar auswählen.
  4. Production branch: main.
  5. Framework preset: None.
  6. Build command: leer lassen.
  7. Build output directory: public.
  8. Save and Deploy.

Auf dem Handy installieren

Die neue Cloudflare-Adresse öffnen. Wenn der Browser es unterstützt, oben auf App installieren tippen. Auf iPhone/iPad: Teilen → Zum Home-Bildschirm. Danach erscheint Job Radar mit eigenem Radar-Icon auf dem Homescreen und startet im App-Modus ohne Browserleiste.

Automatische Updates

Cloudflare Pages kann das GitHub-Repository bei jedem Push automatisch neu veröffentlichen. Die tägliche Job-Radar-Aktualisierung bleibt dadurch automatisch aktuell.
